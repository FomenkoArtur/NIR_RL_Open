Запускать в таком порядке (всё из папки проекта):

Проверка CUDA и зависимости (один раз).
python -c "import torch; print(torch.cuda.is_available())" должно напечатать True. Если False, поставьте PyTorch со сборкой CUDA с pytorch.org.
pip install -r requirements.txt ставит psutil, optuna, cma и остальное.
python bench_train.py выбирает видеокарту, потоки и число параллельных сред для обучения и пишет tuned/hw_train.json.
python hw_tune.py подбирает число воркеров для подбора архитектуры и процессов для подбора ПИД и пишет tuned/hw_tune.json. Это нужно, чтобы подбор шёл с оптимальной загрузкой.
python tune_pid.py подбирает ПИД-эталон (tuned/pid_int.json). Он нужен RL как эталон и учитель, поэтому идёт первым. Если ПИД вас устраивает, пропустите.
python tune_cnn.py 60 подбирает архитектуру RL (tuned/cnn_rl.json). Это самый долгий этап, его можно прервать и продолжить позже.
python run_gui.py запускает GUI. Там кнопка «Обучить регулятор» делает полное обучение с найденной архитектурой на вашей видеокарте. Затем идут «Моделирование», «Таблица 1» и карты Шухарта.
