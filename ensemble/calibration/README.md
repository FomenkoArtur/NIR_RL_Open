# Калибровка моделей (архив)

Этот тест использовался на этапе `--wp CAL` — для отбора 4 генераторов из 10 бесплатных моделей.
Он проверял API на **2 ОДУ** (упрощённая версия).

После WP1 финальный `plant_equations.py` содержит **8 ОДУ**, поэтому `test_cal.py` больше не актуален.
Финальный API проверяется в `ensemble/acceptance/test_wp1.py` (15 тестов).

Запуск при необходимости:
    python -m pytest ensemble/calibration/test_cal.py -q
